# Промпт: базовая версия браузерной "Монополии" для игры с друзьями

Скопируй это в Claude Code / Cursor / другой агент и запускай.

---

Сделай браузерную мультиплеерную игру в духе "Монополии" для игры с друзьями по вечерам (не менее 2 и не более 6 игроков в комнате). Это MVP — базовая версия, дальше буду докидывать функционал (торговля, строительство, аукционы и т.д.), поэтому код должен быть чистым и легко расширяемым.

## Стек
- Бэкенд: Node.js + Express + Socket.io
- Фронтенд: одностраничное приложение, обычный HTML/CSS/JS (без сборщиков, без фреймворков — максимально просто для старта)
- Состояние комнаты и игры хранится в памяти сервера (в объекте/Map по room id), без базы данных
- Один `npm run dev` поднимает и сервер, и отдаёт статику клиенту

## Комнаты и подключение
- На старте: экран с полем "введи имя" + кнопки "Создать комнату" / "Присоединиться по коду"
- Комната имеет короткий код (4 символа), которым можно поделиться с друзьями
- Хост комнаты нажимает "Начать игру", когда все подключились (от 2 до 6 игроков)
- Если игрок обновил страницу — должен переподключиться в свою комнату (можно просто через localStorage хранить room id + player id на клиенте)

## Игровое поле
- Сгенерируй простое поле на 24 клетки по кругу (не используй названия/бренд Monopoly/Hasbro — придумай нейтральные "улицы" или дай возможность легко переименовать клетки позже через конфиг-файл)
- Типы клеток:
  - Property (можно купить) — у каждой: название, цена покупки, размер ренты
  - Старт (клетка "Start") — при проходе через неё игрок получает бонус (например, 200)
  - Налог — списывает фиксированную сумму
  - Шанс/Казна — вытягивает случайную карточку из небольшого преднаписанного списка (штраф/бонус деньгами), без сложных эффектов пока
  - Тюрьма (просто клетка "в гостях", без ареста в этой версии) и "Отправляйся в тюрьму" — телепортирует на клетку тюрьмы и пропускает следующий бросок
- Вынеси конфиг поля (клетки, цены, ренту) в отдельный файл, чтобы легко редактировать

## Игровой цикл
- Ходы строго по кругу, сервер знает, чей сейчас ход, и не принимает действия от других игроков
- Бросок 2 кубиков (кнопка "Бросить кубики"), анимация перемещения фишки по клеткам
- При попадании на property:
  - Если клетка свободна — предложить купить (да/нет)
  - Если занята другим игроком — автоматически списать ренту в его пользу
  - Если куплена самим игроком — ничего не происходит
- Дубль на кубиках — дополнительный бросок (без лимита в 3 дубля пока, просто ещё один ход)
- Банкротство: если у игрока при списании денег баланс уходит в минус и покрыть нечем — игрок выбывает, его property становятся свободными
- Игра заканчивается, когда остаётся один игрок, либо по кнопке хоста "Завершить игру"

## Интерфейс
- Компактное поле по кругу (можно просто прямоугольная сетка клеток, не обязательно красиво рисовать ромбом)
- Фишки игроков разных цветов на клетках
- Панель сбоку: список игроков, их баланс, кто сейчас ходит
- Лог событий внизу/сбоку: "Игрок X купил Y", "Игрок Y заплатил ренту Z", и т.д. (текстовый лог, обновляется в реальном времени у всех)
- Простой текстовый чат в реальном времени (отдельное окошко, не влияет на игровую логику)

## Технические требования
- Вся игровая логика и проверка правил — на сервере (клиент не должен доверять своим расчётам, только показывать то, что прислал сервер)
- События через Socket.io: `roll_dice`, `buy_property`, `end_turn`, `chat_message` и т.д. — используй понятные имена событий
- Структурируй код так, чтобы было легко добавить: торговлю между игроками, покупку домов/отелей, аукцион при отказе от покупки — то есть отдели "движок правил" от сокет-обработчиков
- Не нужна авторизация, base не критично к security — это игрушка для друзей в локальной комнате

## Что НЕ делать в этой версии (сделаем позже)
- Торговля между игроками
- Строительство домов/отелей
- Аукцион на клетке при отказе от покупки
- Настоящая тюрьма с механикой залога/пропуска ходов
- Красивая графика/анимации — сначала функциональность
